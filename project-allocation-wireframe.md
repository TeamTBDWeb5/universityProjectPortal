Design a Complete Low-Fidelity Wireframe for a Web-Based Final Year Project Allocation and Supervision System

Design a complete low-fidelity grayscale wireframe for a Web-Based Final Year Project Allocation and Supervision System for a university department.

The system has three user roles:
- Student
- Lecturer/Supervisor
- Admin/Project Coordinator

The design should look like a modern university management portal similar to Canvas LMS, Moodle, or Microsoft Teams, using a dashboard layout with a top navigation bar, left sidebar, and main content area.

Do not focus on colors. Use grayscale placeholders, simple icons, cards, tables, forms, and buttons. The emphasis should be on layout, usability, navigation, and user flow.

---

# Global Layout

Every dashboard should contain:

### Top Navigation Bar

- University Logo
- System Name
- Search Bar
- Notification Icon
- User Profile
- Logout Button

### Left Sidebar

Display menu items depending on the user's role.

### Main Content

Use cards, tables, graphs, forms, and action buttons.

Every page should include:
- Page Title
- Breadcrumb Navigation
- Search Bar (where applicable)
- Filter Options (where applicable)
- Success/Error Notification placeholders
- Back Button where necessary
